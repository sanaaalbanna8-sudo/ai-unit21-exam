امتحان الوحدة 21 — رفع على GitHub + ربط النتائج
================================================

الملفات المهمة
--------------
index.html
css/style.css
js/config.js          ← رابط Apps Script هنا
js/questions.js
js/exam.js
google-apps-script.gs ← يُلصق في Google Apps Script (ليس على Pages)


أ) رفع الامتحان على GitHub Pages
--------------------------------
1) أنشئي مستودع جديد (مثلاً ai-unit21-exam) وارفع محتويات هذا المجلد.
2) Settings → Pages → Source: Deploy from branch → main / root
3) رابط الطالبات يصير مثل:
   https://USERNAME.github.io/ai-unit21-exam/


ب) ربط النتائج بجدول Google
---------------------------
1) أنشئي جدول Sheets جديد.
2) من الجدول: Extensions → Apps Script
3) الصقي محتوى google-apps-script.gs
4) غيّري:
   var SHEET_ID = "....";
   (من رابط الجدول بين /d/ و /edit)
5) احفظي → Deploy → New deployment → Web app
   - Execute as: Me / أنا
   - Who has access: Anyone / أي شخص   ← مهم جدًا
6) انسخي رابط ينتهي بـ /exec
7) افتحيه في المتصفح: لازم يطلع OK فقط
8) الصقيه في js/config.js:
   sheetsUrl: "https://script.google.com/macros/s/...../exec"
9) ادفع التعديل لـ GitHub


ج) اختبار سريع
--------------
1) افتحي صفحة الامتحان من GitHub Pages
2) امتحني باسمكِ وسلّمي
3) راجعي أوراق الجدول:
   - امتحان AI الوحدة 21 - ملخص
   - امتحان AI الوحدة 21 - تفاصيل
   - امتحان AI الوحدة 21 - الاخطاء
   - امتحان AI الوحدة 21 - التصنيف


إذا ما ظهرت النتائج
-------------------
غالبًا النشر على "أنا فقط" → يعطي 403.
أعيدي Deploy بإصدار جديد مع Anyone، وحدّثي الرابط في config.js
